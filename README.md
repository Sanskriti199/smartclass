# SmartClass – Frontend

SmartClass is an AI-powered attendance system designed to make classroom attendance more secure, efficient, and convenient.

This repository contains the **frontend application** of SmartClass, providing the web interface and user-facing experience for the attendance system.

---

## ✨ Features

- 👨‍🏫 Teacher Portal
- 👨‍🎓 Student Portal
- 🔐 User Authentication Interface
- 📊 Attendance Management Interface
- 🎨 Custom UI with responsive styling
- ⚡ Interactive JavaScript components
- 🖼️ Custom assets and typography
- 🔗 Flask-based web application

---

## 🛠️ Tech Stack

- **Python**
- **Flask**
- **HTML5**
- **CSS3**
- **JavaScript**
- **Gunicorn**
- **Vercel**
